# docker-ai-agent

This repository contains a minimal project with a `backend` Python service and a `static_html` site. Use the provided `scripts/init_and_push.cmd` to initialize a git repo and push to GitHub.

Quick start:

1. Open a `cmd.exe` in the project root (`c:\Users\Gabe\Desktop\docker-ai-agent`).
2. Run `scripts\init_and_push.cmd user/repo` (replace `user/repo` with your GitHub repository name).

If you prefer GUI: sign into GitHub in VS Code (Accounts menu), then use Source Control to initialize and publish the repository.
